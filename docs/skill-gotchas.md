# Skill gotchas

One line per gotcha: the reference file it belongs in, then the fact.

- SKILL.md Step 0: in an Orca worker session the plugin skill was not registered (`Skill` said unknown) and its guard hook did not load; adding the `hooks` block with the stable marketplace path to `.claude/settings.json` made the guard live in the same session (canary then blocked).
- references/setup.md: context-mode trims any Bash output over ~5 KB to a search stub; keep recon commands' output short (`cut -c1-120`, `head`) or write to a file and summarise.
- references/platform-ps1.md: dumpsxiso extracts `.STR` files as 2336-byte Mode2 sectors (subheader + data, no sync/header); ffmpeg's `psxstr` demuxer rejects them ("Invalid parameters") until each sector gets the 12-byte sync + 4-byte header back (`tools/str2352.py`), then `ffmpeg -f psxstr` decodes the FMV fine.
- references/pipeline.md §Recon (PS1 overlays): find an overlay's load address by trying every base in steps of 4 and counting string starts hit by u32 pointers or lui/addiu pairs; the right base stood out at 327/329 here (0x8009b4b0, which the EXE marks with an overlay-id word).
- references/pipeline.md §Recon: a pure-Python byte-by-byte SJIS scanner over an 85 MB graphics archive runs for many minutes; scan text archives first and the graphics archive in the background.
- references/emulator-qa.md §Debug tool (saves): a game can refuse to write a save it only ever updates (here the clear-data file, read before every write, retried forever when missing); trace the BIOS B0 card calls (open/read/write with the file name: tools/debug/cardtrace.lua, on_exec 0xB0 + t1) before suspecting the emulator, then build the missing file with the save editor.
- references/emulator-qa.md §Debug tool (routes): a yes/no cursor ignored a direction pressed 10 frames before circle inside a mash loop, but took it with ~40-60 frames between them (play.py proved it); give direction+confirm pairs a long gap.
- references/pipeline.md §Extract (coverage): a run scanner that needs kana and 3+ characters misses short kanji-only strings in fixed-stride tables (満月, 立方体, １本 in a quiz table with no per-string pointer); after the pointer walk, also look for NUL-bounded runs of 2+ double-byte characters and check the strides of any unreferenced block.
- references/pipeline.md §Extract (bytecode): ASCII bytes inside a script's text (dev leftovers like `text_on;`) read as argument counts desync the tokenizer; and dead bytes after a goto can swallow the next jump target. Re-sync the tokenizer at every jump target (cut any token that spans one) and iterate until the target set is stable.
- references/pipeline.md §Extract (coverage test): op arguments and header tables decode as SJIS (a jump offset 0x5894 is 嚢); give each source its structural byte ranges and move a run's start past them before requiring a row there, rather than waiving each hit.
- references/translation.md §Batches (TSV parts): an Edit whose old_string ends in `<id><TAB>` (to insert a row before it) can drop that tab, gluing id and text; `batches.py check` then dies on a 1-column row. Anchor inserts on the end of the previous line instead.
- references/translation.md §Review: with no subagents and codex out of credits, a whole-script scan (near-miss names by edit distance, katakana term -> most common English, EN/JP length outliers) found the real Important (a place spelled two ways) that a ~1% sampled read missed; consider shipping such a scan as a script (this repo: tools/review_scan.py).
- references/platform-ps1.md §EXE and overlays: a lui/addiu xref scan must stop at ANY write to the register (a load into it, ALU rd, jal), not only at another lui; one that didn't paired `lui a0,0x8002` with `lw v1,0x114(a0)` after `lw a0,..(s0)` and invented a string (and relocation would have rewritten that load). Also stop after the low itself writes rX.
- references/platform-ps1.md §EXE and overlays: an inline literal copy (`addiu rT` then lw/lb at fixed offsets into a stack buffer) copies exactly the JP byte count + NUL wherever the string lives: relocation does not lift it, and NUL padding after the slot does not either; cap the English at copy size - 1 (this repo: codetext.copy_size).
- references/pipeline.md §Checks: tail-sharing strings (a pointer to the 3rd byte of another string) are common in PS1 name tables; writing both in place lets the tail overwrite the head's English. Move the head when the head's English does not end in the tail's.
- references/platform-ps1.md: PS1 games with a malloc-style heap put a 0x10-byte header (prev, next, size incl. header) before each block; reading dst-0x10 at the file loader gives every load buffer's capacity in one warp (this repo: tools/debug/fileslog.lua blk=).
- references/platform-ps1.md: armips equs are case-insensitive text substitutions: a label name_commit next to 'NAME_COMMIT equ ...' becomes 'Parse error 0x8001FC00'; name labels apart from equs.
- references/platform-ps1.md: armips assembled 'addiu t3, t4, -0x8260' (immediate out of the 16-bit signed range) without an error and the compare never matched; load such constants with ori + subu.
- references/platform-ps1.md: STR v2 frames end with a 10-bit 0x1FF end code after the last block (then zero pad to 32 bits); a re-encoded frame without it makes the game's movie player quit. Editing captions in place: v2 has absolute DC per block, so only the macroblocks a caption touches need re-encoding (tools/mdec.py in favorite-dear-junpaku-no-yogensha-en); no jPSXdec/Java needed.
- emulator-qa.md: qa_gate.py init without --glob picks up every *sheet* PNG (warp.py's own sheet.png/sheet_N.png too); pass --glob "qa_sheet*.png" when the tour has both kinds.
